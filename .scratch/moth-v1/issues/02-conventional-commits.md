# 02: Conventional commits enforced

**What to build:** A contributor writing a commit message that does not follow Conventional Commits is stopped locally, before the commit exists, rather than discovering it in review.

**Blocked by:** 01 (project scaffold)

**Status:** ready-for-agent

- [ ] A non-conforming commit message is rejected before the commit is created
- [ ] A conforming message commits with no friction
- [ ] Hooks install as part of installing dependencies, with no separate manual step
- [ ] The accepted commit types are documented in the repo
