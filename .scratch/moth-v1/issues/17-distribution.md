# 17: Distribution

**What to build:** Someone who has heard of moth can install it in one command, on a Mac, in a CI container, or into a JavaScript project.

**Blocked by:** 16 (help text audit)

**Status:** ready-for-agent

- [ ] The binary is installable via Homebrew
- [ ] A curl-based installer places a working binary on the PATH
- [ ] An npm package vendors the binary so it runs without paying a Node startup cost at runtime
- [ ] Every install route reports the correct version
- [ ] Installation is documented for each route
